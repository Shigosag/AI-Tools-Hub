# 🚀 AI Tools Hub

A modern full-stack AI tools demo platform built with Next.js, TypeScript, Express.js, Tailwind CSS, and scalable production-style architecture.

---

## ✨ Features

- AI Text Generator (demo UI)
- AI Code Assistant (demo UI)
- AI Summarizer (demo UI)
- AI Email Generator (demo UI)
- Modern dark/red UI theme
- Responsive dashboard design
- Modular scalable architecture
- Clean component-based frontend
- REST API backend (Express.js)
- TypeScript support

## ⚙️ Installation & Setup

## Clone Repository
```bash
git clone https://github.com/Shigosag/AI-Tools-Hub.git
cd AI-Tools-Hub
```

## Run Frontend
```bash
cd client
npm install
npm run dev
```

## 🌐 Frontend URL: http://localhost:3000

## Run Backend
```bash
cd server
npm install
npm run dev
```

## 🌐 Backend URL: http://localhost:5000
